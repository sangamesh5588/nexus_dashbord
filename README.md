> **Nexus Dashboard** is a mission-control operations platform integrating **Anthropic Claude AI**, **Google Maps Platform**, and **Supabase**. It delivers automated business intelligence, live geospatial tracking, and automated spreadsheet report generation.

---

## ✨ Features

- 🤖 **Anthropic Claude Intelligence:** Embedded AI assistant providing automated executive summaries, report generation, and data query synthesis.
- 🗺️ **Geospatial Asset Tracking:** Real-time marker clusters and interactive map viewports via `@vis.gl/react-google-maps`.
- 📊 **Spreadsheet Data Pipeline:** Automatic XLSX ingestion, parsing, and export using SheetJS (`xlsx`).
- 📧 **Automated Operational Mailer:** Background email dispatch and notification triggers with Nodemailer.
